# 12 模組翻車診斷檢查表與重構範例 (`diagnostic-checklist.zh-TW.md`)

當執行 **`real-me-rescue`（不像本人廢片診斷與重構）** 時，使用本表快速定位病因並插入急救模組。
**`M01–M12` 為標準必檢基準**，**`+ Custom` 則作為開放式自訂情境兜底檢查**（不限於 12 項，凡發現使用者自訂視角、道具或構圖異常皆一併診斷修復）。

---

## 1. 12 大標準檢查指標與急救處方速查表

| 模組代號與名稱 | 明確檢查標準（AI 比對「本人原圖 vs. 輸出圖／Prompt」查什麼？） | 必加急救處方模組 |
| :--- | :--- | :--- |
| **`M01` 原圖場景與穿搭隔離／保留** | 拍新寫真時是否誤留了原圖房間、桌子、衣服或坐姿？或原圖修圖時誤換了原本的背景與穿搭？ | **第一句場景隔離前綴**：`請只把上傳照片作為人物身分參考，用於保留本人真實長相。不要保留原照片裡的背景、衣服、道具、坐姿、拍攝環境和原始構圖。請重新生成一張全新的寫真。` *(若為原圖修圖則改為鎖定原場景與穿搭)* |
| **`M02` 10 點五官骨相與比例** | 臉型、三庭五眼比例、眉眼結構、眼距眼摺、鼻樑鼻頭、唇厚、下頜線是否被換成「V 臉大眼網紅模板」或歐美化？ | **10 點五官骨相鎖定**：`請嚴格保留人物真實身分特徵，包括臉型、三庭五眼比例、眉眼結構、眼睛形狀與眼摺、鼻樑與鼻頭、嘴唇厚薄與下頜線。不要把人物變成陌生人，不要歐美化，不要網紅臉化，不要生成 AI 假臉。` |
| **`M03` 年齡感、原生膚色與氣質** | 成熟穩重氣質是否被畫成「幼態學生臉」或顯老？自然暖調／健康膚色是否被漂白成「死白冷白皮」？ | **年齡、膚色與氣質鎖定**：`嚴格維持原圖人物的真實年齡感、原生自然膚色（禁止漂白成假白冷白皮）與個人氣質（{填入觀察到的氣質}），避免幼態化或過度醫美感。` |
| **`M04` 髮際線與髮型 3 變數** | 髮際線高低是否改變？無瀏海是否被強加空氣瀏海？寫「黑髮」是否變成一坨無層次的「死黑假髮塊」？ | **髮際線與髮型 3 變數處方**：`保留原圖真實髮際線、頭髮長度體系與有無瀏海屬性（無瀏海絕不強加瀏海）。若原圖為黑髮，請不要生成純黑或死黑頭髮，請處理為具層次感與通透感的深棕黑、黑茶色或柔和深咖色，並帶自然微碎髮（natural flyaway hairs）。` |
| **`M05` 真實膚質肌理與眼神光** | 皮膚是否被磨成「無毛孔塑膠娃娃肌」？額頭鼻樑是否油光死白？瞳孔是否混濁缺乏真實眼神光？ | **真實感細節落點**：`重點呈現自然皮膚紋理、細微毛孔（natural skin texture, subtle pores）、真實眼神光（realistic catchlights in the eyes）、柔和自然高光過渡（smooth highlight roll-off），拒絕過度磨皮美顏與塑膠皮膚（no plastic skin）。` |
| **`M06` 眼神流向與動態微表情** | 人物是否死盯鏡頭擺出「影樓標準假笑」，缺乏動作正在發生的瞬間感與自然微不對稱？ | **瞬間捕捉與眼神流向處方**：`動作像正在發生而非完成後靜止擺拍；表情像情緒剛剛流動出來，允許自然微不對稱，允許笑容正在展開或剛收住的一瞬間，眼神自然柔和有溫度。` |
| **`M07` 鏡頭焦段與臉部透視變形** | 是否因缺乏焦段約束導致廣角大鼻頭／臉部邊緣畸變？或背景變成假摳圖高斯模糊而非光學散景？ | **人像焦段與光學散景鎖定**：`呈現 {50mm / 85mm} 標準人像鏡頭透視感與 {f/2 / f/2.8} 自然景深，避免廣角臉部邊緣變形或大鼻頭畸變，背景呈現真實光學散景（natural optical bokeh）而非假摳圖模糊。` |
| **`M08` 光線方向與明暗融合度** | 是否因平光變「扁平大餅臉」、頂光出現黑眼圈，或人物臉部受光方向與背景環境光不一致（假貼圖感）？ | **方向光與環境融合處方**：`採用方向明確的柔和光線（如左側自然窗光或柔光箱漫射光），讓臉部受光方向與環境光完全一致，陰影過渡柔和立體，消除頂光眼下黑影與生硬合成貼圖感。` |
| **`M09` 色調失真與濾鏡過載** | 是否擅自套用了未指定的重度復古黃綠濾鏡、高飽和色偏，或同時混用多種底片詞導致膚色髒濁？ | **原生色彩／單一底片錨點**：`{預設：維持原圖自然真實的攝影色彩與乾淨通透膚色，不套用未指定的濃重濾鏡；或僅錨定單一底片色調如 Kodak Portra 400，避免多重濾鏡疊加造成色偏}。` |
| **`M10` 九宮格／多圖分鏡防複讀** | `3×3` 或 `4×4` 多格圖是否每一格都重複同一個 45° 角、同一種半身景別與同一個微笑？ | **防重複約束 ＋ 逐格分鏡表**：`請避免整組圖片出現相同角度、相同站位、相同構圖和相同姿勢的重複。` 並明確列出每一格的景別（特寫／半身／全身／坐姿）與角度變化。 |
| **`M11` 雙人空間站位與手部歸屬** | 雙人照是否出現手臂穿模、分不清是誰的左手／右手，或兩人五官互相影響而越長越像（臉部同質化）？ | **雙人獨立鎖臉與空間手部座標**：`分別獨立鎖定人物 A 與人物 B 的五官特徵（禁止雙人臉部同質化），並明確定義：{誰在左側/右側/前景/後景，誰用左手/右手接觸哪個具體部位，以及非對稱眼神流向}。` |
| **`M12` 成年人頭身與肢體比例** | 頭肩比是否變成「頭大身小的棒棒糖／小孩比例」、脖子過長過短，或手指與關節結構扭曲？ | **成年人頭身比例與結構約束**：`請特別注意臉部比例、頭身比例、肩寬、脖頸長度、手臂長度與手掌大小皆符合真實成年人自然協調比例，身體接觸符合真實透視結構，禁止頭大身小、手臂穿模或手指變形。` |
| **`+ Custom` 開放式自訂情境診斷** | 使用者自訂的特殊視角（俯拍／仰拍）、指定道具、互動動作或服裝細節是否有遺漏或崩壞？ | **自訂情境強化修復**：在維持上述鎖臉與光學真實感的前提下，針對使用者被遺漏或變形的自訂指令進行精確描述強化。 |

## 2. Prompt 診斷與重構前後對比範例

### ❌ 重構前（常見的失敗 Prompt）
> 「幫我用這張照片生成一張很有高級感、電影感、韓系膠片感的咖啡廳美女寫真，要像我本人，高清真實，長黑髮空氣瀏海。」
> *(觸發診斷指標：`[M01]` 漏寫場景隔離、`[M02/M03]` 寫「美女」觸發網紅模板與假白膚色、`[M04]` 強套「長黑髮空氣瀏海」破壞本人髮際線並造成死黑假髮感、`[M05/M07/M08]` 堆砌「高級感／電影感／高清」空泛詞而無鏡頭焦段與毛孔眼神光落點。)*

### ✅ 重構後（經 `real-me-rescue` 修復的攝影企劃級 Prompt）
```markdown
請只把上傳照片作為人物身分參考，用於保留本人真實長相。不要保留原照片裡的背景、衣服、坐姿和原始構圖。請重新生成一張全新的「韓系膠片感咖啡廳生活方式人像」。

【身分與髮型鎖定（M02 / M03 / M04）】
請嚴格保留人物真實身分特徵，包括臉型、三庭五眼比例、眉眼結構、眼睛、鼻子、嘴唇、原生膚色、真實年齡感、髮際線和整體氣質。
保持原圖的頭髮長度體系與有無瀏海特徵，髮色處理為具層次感與通透感的深棕黑或黑茶色（避免純黑死黑），保留自然微碎髮。

【攝影企劃與光學細節（M05 / M06 / M07 / M08 / M09）】
半身構圖（half-body framing），略高機位（slightly high angle），呈現 50mm 鏡頭感與 f/2 景深感。左側大窗自然柔光（soft natural window light），人物受光方向與環境光一致，溫暖柔和陰影過渡。整體色調錨定單一 Kodak Portra 400 膠片色調。人物表情自然鬆弛，像在咖啡廳交談間剛轉頭微笑的抓拍瞬間。
重點呈現自然皮膚紋理、細微毛孔（subtle pores）、真實眼神光（realistic catchlights）、真實針織布料紋理與光學背景散景。

【負面約束】
不要把人物變成陌生人，不要歐美化，不要網紅臉，不要過度美顏磨皮，不要塑膠皮膚（no plastic skin），不要假白冷白皮，不要生成 AI 假臉，不要手部變形。
```
