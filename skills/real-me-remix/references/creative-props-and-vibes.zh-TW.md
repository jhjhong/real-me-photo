# 使用者自訂 Prompt 銜接守則與可選二創詞庫 (`creative-props-and-vibes.zh-TW.md`)

本參考指南的核心目的：確保**不論使用者貼上什麼樣的多樣化 Prompt 或個人風格指令**，都能在不預先綁定統一風格的前提下，**100% 依附使用者的指令並守住本人真實五官不失真**。

---

## 1. 通用銜接三大鐵律（不覆蓋使用者風格、只做真我鎖臉護航）

切勿在 Skill 中硬套固定模板給所有人。請根據使用者輸入的 Prompt 內容，動態套用以下三條通用守則：

### 守則 A：依使用者指令決定「原圖元素去留」（Selective Retention）
- **當使用者的 Prompt 要求「保留原圖服裝、配件或表情」時**：
  - 鎖定上傳照片中的衣著款式、顏色、配件與表情神態。
  - 若上傳照片為半身自拍，而使用者的 Prompt 要求全身入鏡，則指示模型**「保留原圖上衣與配件，並依相同穿搭風格自然向下延展全身衣著與鞋履，僅移除原自拍背景」**。
- **當使用者的 Prompt 指定了「新服裝、新造型」或未要求保留原衣服時**：
  - 僅將上傳照片作為臉部五官與髮型基礎的身分參考，拋棄原圖背景、衣服與姿勢，完全依使用者的描述生成新畫面。

### 守則 B：特殊視角、極端透視或特殊比例下的「鎖臉防失真」原則
- 當使用者的 Prompt 明確要求特殊機位（如垂直俯拍、極低角度仰拍、廣角魚眼）或特殊視覺比例時：
  - **絕對不要用死板的比例限制去抵銷使用者想要的效果！**
  - 正確做法是：**完整保留使用者要求的視角與比例設定**，同時補上「**由真實相機光學透視自然形成該比例，且人物臉部必須維持 100% 真實人類五官骨相、自然皮膚毛孔（subtle pores）與真實眼神光（realistic catchlights），嚴禁退化為卡通 Q 版或塑膠公仔假臉**」。

### 守則 C：不干預使用者原始 Prompt 結構（Non-Intrusive Handling）
- **使用者已提供完整 Prompt**：原封不動保留使用者寫的所有場景、構圖、佔比、光影與風格字句，僅將「本人 10 點五官與真實肌膚約束」無縫銜接上去。
- **使用者只給簡短幾個字**：只有當使用者僅輸入簡短構想（例如「幫我加點好玩的道具」）並希望你幫忙展開時，才從下方的可選詞庫補充細節。

## 2. 可選二創記憶點與微動作詞庫（僅在使用者未指定細節、需要幫忙展開時選用）

- **視覺記憶點道具（提醒 AI 進行二創設計，不死板照搬）**：
  - 日常與電影感：咖啡杯、復古底片相機、有線耳機、花束、黑膠唱片、街頭小吃、珍珠奶茶。
  - 活潑與趣味感：棉花糖、泡泡機、透明果凍發夾、彩色串珠戒指、彩色冰棒、毛絨玩偶、小甜品。
- **自然瞬間微表情（避免呆板影樓假笑）**：
  - 動作像正在發生的抓拍瞬間、被逗樂的自然笑意、單眼 wink、托腮、回眸、閉眼感受微風、或是酷颯冷靜表情搭配趣味場景的反差感。
